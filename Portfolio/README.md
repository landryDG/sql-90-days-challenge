# 💼 Portfolio

Ce dossier rassemble les projets que je considère comme les plus représentatifs de mes compétences.

Chaque projet est accompagné d'une documentation présentant :

- la problématique métier ;
- la méthodologie ;
- les analyses réalisées ;
- les recommandations formulées ;
- les compétences développées.

L'objectif est de constituer un portfolio professionnel démontrant ma capacité à résoudre des problématiques Data de manière structurée.
